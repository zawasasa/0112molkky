# ささっとモルック
モルックの得点をスマートフォンで「ささっと」記録するためのWebアプリです。

### 公開 URL
**[ここからあそべます！](https://zawasasa.github.io/0112molkky/)**

## 特徴
- **こどもむけロジック**: 3かいミスしたときに「つづける」か選べます。
- **えらべるリセット**: なまえや写真を残したままやり直せます。
- **こどもむけUI**: すべてひらがな・カタカナ表示です。
- **タップ音**: 心地よいサウンドエフェクト付き。
- **全履歴の表示**: 全ターンの記録をスクロールで確認。
- **カスタムチーム名**: 自由にチーム名を設定できます。
- **チームカラー識別**: 赤チームと青チームで視覚的に識別可能。
- **顔写真アイコン**: スマホのインカメラでアイコンを撮影可能。
- **先行選択**: ゲーム開始時にどちらのチームが先に投げるか選べます。
- **公式ルール準拠**: 50点超過時の25点バック、3回連続ミス（選択可能）。
- **モバイル最適化**: 屋外でも操作しやすい大きなボタン。
- **安心の取り消し機能**: 「まった（Undo）」ボタン。

## 使い方
1. 公開URLにアクセスするか、`index.html` をブラウザで開きます。
2. **対戦のじゅんび**: チーム名の入力、写真撮影、先行チームの選択をしてスタート！
3. 投げ終わったチームの得点を入力します。
4. 自動で次のチームに切り替わります（失格者以外）。
5. 50点ぴったりになれば勝利です！

## 開発
HTML/CSS/JavaScriptのみで構成されており、サーバー不要で動作します。
モバイルでのブックマークや「ホーム画面に追加」をして使うのがおすすめです。
